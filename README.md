# 🌾 ربات فارمینگ بله

یک بازی کشاورزی در پیام‌رسان بله با قابلیت‌های:
- کاشت و فروش ۷ نوع میوه
- سیستم لول و XP
- پرستیژ (۱۰ سطح)
- فروشگاه سکه
- کارگر خودکار
- سفارشات روزانه
- لیدربرد
- هدیه دادن
- فصل‌های چرخشی (هر ۴۵ دقیقه)

## اجرا در گیت‌هاب
1. توکن ربات را در Secrets با نام `BOT_TOKEN` ذخیره کن.
2. توکن پرداخت را در Secrets با نام `PROVIDER_TOKEN` ذخیره کن.
3. workflow به‌صورت خودکار هر ۱۰ دقیقه اجرا می‌شود.
